# Zwicky Box for generating story plots
Zwicky Box records five characters across various settings, objects, crises, and actions to develop story plots.
After five characters are recorded, the program rolls a die to randomly select a particular character, setting, etc. 
The user can accept it or keep rolling a dice to see the other options. Once your preferred story plot is shown. 
The program shows other randomly generated scenarios without using the same tokens.  At the end, the user can generate
20 random story plots (this time with replacement, meaning the selected character and setting are placed back in the pot
for the next draw at a time. If you have generated random plots, the user can record them in the report after the Zwicky Box
and their preferred plot.
